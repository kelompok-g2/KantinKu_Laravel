# Audit akhir pengumpulan

## Siap dari sisi persiapan
- [x] agents.md dan project_guidelines.md tersedia pada branch fitur kedua repo.
- [x] main, dev, feature/context-management tersedia di GitHub kedua repo.
- [x] PR fitur menuju dev sudah dibuat pada kedua repo.
- [x] Konteks dokumentasi awal dirujuk dengan permalink.
- [x] Formulir log, naskah video, panduan screenshot dan online text draft disiapkan.

## Wajib dituntaskan dengan bukti aktual
- [ ] main kedua repo protected; wajib PR dan approving review; screenshot tersimpan.
- [ ] PR direview anggota lain pada versi terbaru dan merged.
- [ ] Artefak diteruskan ke main melalui PR rilis, bukan push langsung.
- [ ] Rules aktif diverifikasi di sesi baru Flutter dan Laravel, screenshot tersimpan.
- [ ] Struktur branch kedua repo difoto sebelum feature branch dihapus.
- [ ] Prompt 2/3 asli diterima dan empat kasus tes dicatat.
- [ ] PDF satu halaman final berisi hasil aktual, bukan template kosong.
- [ ] Skenario 2/3 asli dicocokkan; aplikasi benar-benar normal, rusak dan pulih.
- [ ] Video sekitar tiga menit diunggah, tautan dan izin akses diuji.
- [ ] Anggota/NIM dan link PR rilis di online text dilengkapi.
- [ ] Screenshot, PDF final dan online text diunggah ke LMS sebelum deadline.
- [ ] Semua klaim cocok dengan bukti; tidak ada token/password/data pribadi.

Status ini adalah checklist kerja. Tidak ada bukti review, screenshot atau tes yang
dibuat-buat untuk mencentang persyaratan.
